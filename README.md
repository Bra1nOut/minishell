# Minishell 🐢
Minishell is a 42 school projet where we are recoding a simplified shell.

## Content 📖
Minishell is divided in two big part : parsing and executive.

The parsing parses every characters gived by the user in the program, it will check every "word" and give them a type. It also make some check to ensure that we are not giving "strange things" to the exec part.<br>
The executable receive the parsed arguments, do some check and test, and execute if possible, or return an error if not.

## How to use ? 🔨

Run ```make``` then ```./minishell```<br>
Now you can use it just as the base shell (not everything is managed, it's a "mini" shell☝️)
